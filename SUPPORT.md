# Getting help and support

Thanks for using NEXUS-Q. This page explains where to ask questions, report problems, and find the right project information.

## Before asking

1. Check the README and documentation index.
2. Read AGENT.md when using an AI coding agent, and CONTRIBUTING.md before proposing code changes.
3. Search existing Discussions, Issues, and Pull Requests.
4. Include the NEXUS-Q version or commit, operating system, relevant feature flags, exact command, and a minimal reproducible example when applicable. Redact secrets and private data.

## Where to go

- Usage questions and troubleshooting: [GitHub Discussions — Q&A](https://github.com/lecodev-26/nexus-q/discussions/categories/q-a).
- Design proposals and technical debate: [GitHub Discussions](https://github.com/lecodev-26/nexus-q/discussions).
- Confirmed bugs: [Bug report form](https://github.com/lecodev-26/nexus-q/issues/new?template=bug_report.yml).
- Feature proposals: [Feature request form](https://github.com/lecodev-26/nexus-q/issues/new?template=feature_request.yml).
- Documentation corrections: [Documentation issue form](https://github.com/lecodev-26/nexus-q/issues/new?template=documentation.yml).
- Scoped engineering work: [Task form](https://github.com/lecodev-26/nexus-q/issues/new?template=task.yml).
- Code contributions: fork the repository, create a focused branch, and open a Pull Request. You do not need to contact the maintainer first for a clearly scoped, non-sensitive change.

## Security vulnerabilities

**Do not report vulnerabilities in public Issues, Discussions, Pull Requests, or comments.** Use [GitHub private vulnerability reporting](https://github.com/lecodev-26/nexus-q/security/advisories/new) and follow SECURITY.md. Do not publish exploit steps, proof-of-concept code, affected secrets, or sensitive reproduction details.

## Support expectations

NEXUS-Q is maintained on a best-effort basis. A response time or fix is not guaranteed. Public discussion is preferred so non-sensitive project knowledge can benefit everyone. Please be patient and respectful; see CODE_OF_CONDUCT.md.
