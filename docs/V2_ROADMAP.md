# NEXUS-Q v2 — Roadmap placeholder

This document intentionally starts as a high-level hand-off. The complete v2 plan will be designed before implementation begins on the `nexusqv2` branch.

## Primary objective

Reduce the performance gap identified by the v1 PQC Benchmark Arena while preserving correctness, constant-time/security requirements, portability and maintainability.

## Initial workstreams

1. Benchmark baseline and target thresholds
2. CPU/profile analysis
3. ML-KEM optimization
4. ML-DSA optimization
5. Memory/allocation optimization
6. SIMD/vectorization and parallelism assessment
7. Backend/primitive strategy
8. Correctness and interoperability regression suite
9. Security/fuzz regression gates
10. Final Arena comparison and release decision

No detailed acceptance threshold is declared here yet; it will be agreed and recorded before v2 implementation starts.
