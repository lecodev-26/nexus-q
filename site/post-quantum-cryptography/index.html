Post-Quantum Cryptography (PQC)

What is post-quantum cryptography?

Post-quantum cryptography (PQC) uses cryptographic algorithms designed to resist attacks from both classical and, where the underlying assumptions hold, quantum computers. It is intended to help protect data and communications that may need to remain confidential or verifiable for many years.

What NEXUS-Q provides

NEXUS-Q is a library-first Rust project with a Rust core, command-line and server interfaces, a C ABI and language bindings. Its documented algorithm family includes ML-KEM and ML-DSA. Exact feature availability depends on the release, package, platform and build configuration; consult the release documentation before adopting a feature.

ML-KEM and ML-DSA

ML-KEM is the NIST-standardized key-encapsulation mechanism specified in FIPS 203. ML-DSA is the digital-signature standard specified in FIPS 204. Older names Kyber and Dilithium are useful search terms and historical names, but the standardized names are ML-KEM and ML-DSA. NEXUS-Q documentation identifies ML-KEM-768 and ML-DSA-65 among its supported profiles.

Open source and licensing

The repository declares dual MIT OR Apache-2.0 licensing. You can inspect the source, release history, build workflows and package metadata before integrating it. Open source does not itself mean independently audited, certified or suitable for every production threat model.

Is NEXUS-Q the Google Nexus Q?

No. NEXUS-Q is an independent open-source post-quantum cryptography software project. It is not affiliated with Google and is unrelated to the discontinued Google Nexus Q media player. This page is about cryptographic software and developer tooling.
