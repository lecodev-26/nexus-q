Post-Quantum Cryptography for Python

Check the package first

The project lists the Python package nexusq on PyPI. The 4.1.2 package information reviewed for this site indicates a source distribution only, with no wheel listed. That means installation may require a local build toolchain and native dependencies; do not assume a prebuilt wheel is available.

Install the published source package

The package installation command is shown below. Confirm the latest release and its supported Python versions on PyPI before using it.

Install command

python -m pip install nexusq==4.1.2

Native runtime and build requirements

The Python binding is based on the NEXUS-Q native library. Follow the binding README for building or locating libnexusq, supported platforms and environment configuration. If the package cannot build on your system, consult the project issue tracker and release notes rather than treating the pip command as a guarantee of compatibility.

Security review

Test interoperability and failure cases in a non-production environment. Review the NEXUS-Q threat model and release notes. The presence of a Python package does not mean every core feature is exposed through Python or independently audited.
