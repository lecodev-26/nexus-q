Build post-quantum features with Rust.

NEXUS-Q is a Rust-first, library-first cryptographic project. Its Rust crates expose the core and selected cryptographic modules, while CLI, server and language bindings build on the same engine.

Post-Quantum Cryptography in Rust

Install the Rust toolchain

Install a current Rust toolchain with rustup and make sure Cargo is available. The project documentation for the v4.1.2 development line specifies Rust 1.88 or newer for building current main. Check the release-specific requirements before choosing an older version.

Add the crate

For an application using the published top-level crate, add the dependency with Cargo. Check crates.io for the current version and API before pinning it.

Example dependency

cargo add nexusq

Explore focused crates

The project publishes focused crates for core functionality and algorithm modules, including nexusq-core, nexusq-ml-kem and nexusq-ml-dsa. Choose the narrowest public API that meets your use case and follow its documentation.

Validate before production

Run the examples and tests for the exact crate version and target platform. Review key lifecycle, randomness, error handling, interoperability and the project threat model. A successful build or benchmark is not a security audit.
