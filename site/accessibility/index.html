Accessibility statement

Last reviewed: 24 October 2026

NEXUS-Q aims to make its project website usable by as many people as possible, including people who use assistive technology, keyboard navigation, browser zoom, or reduced-motion settings.

Current measures

  • Responsive layouts intended for mobile and desktop.
  • Visible keyboard-focus styling for interactive elements.
  • Semantic headings, links, buttons, and disclosure controls in the page structure.
  • A reduced-motion preference that disables the animated hero canvas and reduces transitions.
  • Benchmark information presented with explanatory text and a link to the exact measurements.

Known limitation

The site has not yet been independently audited against WCAG 2.2 AA. Some visual contrast, chart screen-reader descriptions, third-party logos, and keyboard/screen-reader interactions may need further testing. This statement is not a claim of conformance or certification.

Report an accessibility issue

Please report the page URL, what you were trying to do, the browser and assistive technology (if relevant), and a description of the barrier through the project issue tracker. Avoid sharing private or sensitive information. We welcome actionable reports and aim to improve the experience over time.
