/ latest accepted diagnostic

Native backend · 21 Oct 2026

The latest local x86-64 diagnostic used an Intel Core i3-N305 with the CPU governor set to powersave, and compared the opt-in native backend with the best eligible per-operation comparator using a matched AWS-LC RNG. Six of nine operations beat the comparator on both median and p95. Three modest gaps remain accepted and documented.

/ how to reproduce

Reproducibility checklist

Record the environment

CPU model and features, OS, target, compiler/toolchain, CPU governor, thermal state, and runner type.

Pin the implementation

Record source revision, dependency versions, comparator version and build flags. Keep native and default paths separate.

Describe the workload

Algorithm and parameter set, operation, input corpus, warmups, sample count, rounds and aggregation method.

Publish raw evidence

Keep normalized JSONL, schema validation, CI run link and report together. A planned adapter is not a measured result.
